# AI Dating Expert
## Purpose of this project
The AI Dating Expert App is a full stack AI application that serves as a dating expert to provide users with personalized dating advice and recommendations by leveraging LLMs based on customized knowledge base.
It can independently call tools and MCP services to complete tasks such as calling map services to recommend nearby restaurants for a date, making date plans and calling calendar services to schedule dates.

By completing the project, the developer will be able to learn the overall workflow to develop a full stack AI application.
